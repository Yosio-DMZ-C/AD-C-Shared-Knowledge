# AD&C Shared Knowledge（旧AgentOS-C Shared Knowledge）

人生の重要な場面で、主要な議論・主張・根拠・反論を比較できるようにし、調べる時間を短縮する公開共有知の基盤です。最上位の目的は、本人のより良い選択を支えることです。

**読んで使うだけでも参加できます。共有知の更新への協力は任意です。** 個人の相談、利用履歴、健康・家族・購入情報を提供する必要はありません。

### 自然な依頼からのSkill選択（入口を取得できたAI向け・試験運用）

**最小ルーティング規則**：利用者の自然な依頼の**目的**から既存Skillの適用対象を判断し、該当する場合だけ**現行本文を実取得してから**実行する。単語の出現だけで発動せず、該当しなければ通常の回答を行う。本文を取得できなければ「手順書を利用した」とは言わず、必要なら添付・再取得を相談する。内部の選択処理やチェック表は通常の回答に転載しない。

| 依頼の目的・自然な表現の例 | 取得する実行正本 | 適用条件 |
|---|---|---|
| 山歩き・登山・ハイキング・トレッキングのルートや所要時間を相談／奇岩・展望・神社を巡る散策コース／**キャンプ場から登れる山**／「週末どんづるぼうを2時間」「山城のキャンプ場から三上山へ」 | [山歩きルート検索Playbook v0.3.9（利用者採用Active）](skills/hiking-route-search/SKILL.md) | **具体的な屋外歩行・コース計画の依頼**。地名・人名に「山」が含まれるだけ、山の由来・歴史の単純な質問は適用外 |

**実行順序**：`自然文の目的判定 → 実行正本1件のリンク解決 → SKILL.md全文取得・版確認 → 本文の検索順序と安全ゲートを実行 → 自然言語で回答 → 必須出力を確認`。山歩きの検索は本文の指示どおり**YAMAP先行**であり、この入口を理由に観光・交通の並列検索を先行させない。個人KBに同じ目的の**優先適用手順**が設定されていれば、実取得してその適用範囲を優先する。

**状態の区別**：山歩きPlaybook本文は**利用者採用のActive**だが、共有知全体の正式配布カタログ `catalog.json` は依然として `design_only`・`items: []`。**公開審査済みのActive配布項目とは別**であり、配布・自動インストール・独立チャットでの自動発見成功を主張しない。README自体は公開の参照入口であり、ChatGPT等の新規チャットへ自動で読み込まれる機能ではない。

## 現在地

基本設計 v0.2.0。対象分野、知識の記録契約、レビュー、更新・撤回、AD&Cからの参照方法を定義しています。

**正式配布カタログ掲載のActive主張比較資料・プレイブックは、ともに0件です。** 山歩きSkillの利用者採用Activeは先行試験用であり、この配布件数に含めません。この段階は仕組みと制作範囲の公開であり、医療・法律・金融等の具体的な助言集、専門家紹介サービス、動作する自動同期システムではありません。各分野の共有知は次工程から作ります。

## AD&Cの理念との関係

**どんな玄人も、専門外では素人だ。** AD&C（AI-DODAI & Continuity）は、分野の玄人が当然知っている基本知識・手順・判断基準を共有できる形で整え、AIが利用者の状況に応じて案内することを目指します。**玄人の「当たり前」はAIが案内。人間は、その先の判断に集中する。**

人間の判断を置き換えたり、誰もが専門家になれると約束したりするものではありません。出典・反論・適用条件・更新状況を示し、重要な選択と承認は本人に残します。正式配布カタログのActive項目は現在0件であり、この理念は実装・効果が検証済みという意味ではありません。

## 何をしようとしているか

一から大量の情報を調べなくても、主要な主張、支持・反対の理由、未解決点、関連する専門家の実際の見解へ到達できる比較資料を育てます。答え・勝者・推奨行動の提示は必須にしません。個人差と科学的知識の更新を前提に、異論や判断が分かれる条件を残します。

- 確立した知見だけでなく、有力な仮説も根拠・不確実性・リスクを区別して扱う。
- 人気や投稿数を正しさとせず、出典の質・独立性・反証・適用条件を確認する。
- 主張ごとに専門家の公開発言・論文を紐付ける。発信者、監修者、相談先を区別し、必要時だけ本人に合う候補を検討する。
- 誤りは訂正し、重大な問題は撤回する。古い版を利用している人にも追跡可能な記録を残す。
- 最終的な選択は本人が行い、結果を保証しない。妥当な判断過程と偶然の成功を区別する。

## 山歩きルート検索プレイブック（Active）

- [山歩きルート検索・交通3方式・服装ワークシート v0.3.9](skills/hiking-route-search/SKILL.md)：最初はYAMAPだけ検索し、結果受信→採否判定後に不足分を検索（混載・並列禁止）。起点は安全に交通アクセスできる低所を優先し、原則上り先行。同じ検索結果なら軌跡付き実歩行ログを優先（不在ならモデル）、採用経路の数値を固定。服装は月×最高標高で区分名と定型句を選び、基本携行品まで出力検収。1件適合でルート探索終了。ヤマレコ・海外候補は不成立時のみ。採用後は周辺の見どころ（原則3〜5件）・交通・安全の不足分だけ確認。本編と時間外候補を区別。予定日未指定は直近週末、服装は月×標高の固定表。専門準備が必要・重要安全条件が不明なら共通文で別途相談。冒頭からおすすめ・行程・見どころ・交通の完成形で回答。必須の未実施は1回補完し、任意の追加対応だけ末尾に自然文で最大3件提案（内部の元工程・状態は保持）。**利用者採用済み・全文添付C試験では出力改善を利用者が確認。自然文のみのA試験での自動発見は未証明**、個人の出発地や非公開山行データは含まない。
