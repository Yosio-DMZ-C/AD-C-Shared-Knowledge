## 汎用入口：成果物を作り、必要な箇所だけ検査する（2026-11-17追加）

このPlaybookは作品の種類によらず使う。**4観点は分類棚や必須ゲートではなく、今回の設計に何が関係するかを見落とさないための視点**である。汎用の流れは短く、物理的な取付・組立の厳密検査は該当案件だけに限定する。新規Draft・追加ゲージ・不要な複数形式・毎回の全検査を増やさない。

1. **用途と成果物を固定**：完成したら何ができるか、寸法優先か見た目優先か、何を変更せず保持するかを明確にする。編集できる原本と用途に合った実データを渡す。コンセプト画像は完成した3Dデータではない。
2. **重要な曖昧さを先に数値化**：単位・座標系・基準面・寸法・すき間・角度・最小肉厚・凹凸の符号と深さなど、**今回の機能を決める数値だけ**明示する。固定・組立のある物では部品の相対位置に加え、差し込み方向・手順・工具の進入方向・可動範囲も定義する。「薄く」「面一」「スリット」「貫通」「反転」はどの面からどこまでかを定義し、後から解釈を入れ替えない。わからない値は仮値／推定／実測を区別し、危険でない範囲なら仮値で試作を進める。安全・致命的な適合に関わる1点だけ必要時に聞く。
3. **素モデル→局所変更→実測**：形状・可動・収納・穴の連通だけでなく、**想定した手順で実際に固定・組立・分解できること**を成立させ、本人確定形状を維持したまま該当部分だけ修正する。**「一本の柱」など連続形状を望む場合は、分割生成による中途段差・位置ズレが残っていないか元データの外形で確認する。** 数値での成立と実物の使いやすさは別。印刷実績がなければ印刷PASSとは書かない。
4. **繰返し装飾は幾何学で構成**：格子・回転対称・周期関数・スプライン・CSG／距離場などを優先し、パラメータ（反復数・幅・深さ・周期・位相・交差順）を管理する。円筒への連続模様は `C=2πR`、反復ピッチ `p=C/n` を先に定め、展開図の両端で模様と接線が接続することを確認する。編み紐は交点で上下を交互に表現する。模様だけでなく**背景・紐のどちらを残し削るか**を固定し、残る壁厚を確かめる。中途半端な浮き彫りより線刻／無装飾の方が良いこともある。
5. **ロゴ・文字の表裏と鏡像を確認**：**依頼済みのロゴを装飾変更で消し忘れ／入れ忘れない**よう、既存の採用素材と保持条件を変更差分に含める。実際の元画像・権利を確認し、表／裏のどちらから読ませるか、刻線／凹／凸、最終的な上下を決める。裏面に刻んだ文字を**完成品の底面から正読**できるか、実STLの裏面像で確かめる。「座標上は正しい」では不十分。
6. **必要な形式だけ受渡し**：編集可能なCAD／コード、実立体STLや必要な3MF・STEP・GLB等、実データ再読込による正面／裏面／断面／組立のうち関連するプレビューを用意。CADが水密でもスライサー動作や現物嵌合は別検証。未実施は未実施と記す。
7. **結果の出力・次の一手**：完成原本・変更点・実際に確認した範囲・未検証の1点を示し、既存の作業先に反映・読戻しする。全工程の再承認や固定3巡は不要。

### 4つの設計観点｜必要なものだけ適用する

| 観点 | 確認する問い | 必要な場合の具体的な検証 |
|---|---|---|
| **① 形状・構造** | 目的の形を、指定した数値と強度上の余裕で表現できるか | 寸法、座標系、基準面、断面、穴と開口の連通、底や壁に残す肉厚、回転・鏡像後の形状 |
| **② 構成要素の相互関係** | 他の部品・人・道具・周囲と、実際に接触・固定・組立・移動・分解できるか | 共通座標での穴と相手物の照合、ねじ軸・座金・ナット、工具の進入と回転、取付手順、嵌合公差、移動途中の干渉、保持と取り外し |
| **③ 意匠・表現** | 見た目と意味が設計どおり伝わるか | 柱や面の役割、文様の反復・対称・位相・凹凸、円周の接続、ロゴや文字の表裏・鏡像、装飾と接触面の干渉 |
| **④ 製造・利用** | 必要な形式で作れ、使う場面で目的を果たせるか | 材料、造形方向、積層、支持、精度・公差、スライサー互換、利用動作、編集原本と実データの読戻し、実物評価 |

**②の重要な反例**：
- 現物と固定するなら、穴位置が一致しても**ねじ止めが物理的にできるとは限らない**。ネジ／ボルト・座金・ナット・工具の占有空間、締付け方向、手と工具の到達、仮組みから取り外しまでを確認する。ネジを使わない固定なら接着面・嵌め代など実際の方式を確認し、ネジ検査は不要。
- 部品を嵌め合わせるなら、**完成位置の干渉ゼロだけでは不足**。入口面取り、角のR、すき間、必要な残肉、初期姿勢から回転・スライド・差し込み途中を経た最終姿勢、保持・抜き取りまで調べる。**嵌合する軸の径方向だけでなく、スリットの深さ・幅と柱や突起の実占有範囲を同じ座標で比較し、入口が尖って引っ掛からないか**を見る。組めても外せない、必要な床が破れる、保持物が抜け落ちる場合は機能未達。反転後のロゴの可読方向も確認する。

**検査の重さは4観点の該当条件に応じて決める。** 取付け部品用の全穴表・工具図を無関係な造形に強制せず、逆に嵌合が必要ならメッシュ水密だけで成功としない。設計上の成立、実スライサーの確認、現物の適合は区別して報告する。

## 0. 完成条件を先に固定する

**最優先ルール：数値上の寸法一致、STLの正常性、3MFの生成成功、さらに**最終配置での干渉ゼロ**も、用途に必要な取付け・組立・保持・使用の成功を保証しない。** 相手物があるなら「どの部品の、どの面と面の間で、何を防ぐ／保持／傾けるか」、複数部品なら「どこから、どの向きで差し込み、どう使い、どう外すか」から設計する。

相手物へ組み付ける場合は、用途・向きを確認し、必要な時だけ**ものさしを当てた写真を最小限**依頼する。組付けのない造形・CGへ写真測定を義務付けない。寸法のない部分は「仮寸法」、測れた値は「実測」、画像から推測した値は「推定」と明記し、混ぜない。案件固有の採用条件があれば、それを一般的な値や旧版の数字で上書きしない。

3Dプリント向けの完成品は原則 **編集可能なCAD／コード＋実立体STL＋実STL由来のプレビュー**。3MF・寸法図は依頼や接続検証で必要なときだけ追加する。CG等は利用先に合う形式を選択する。ユーザーがBambu Studio用3MFを指定したら、実際に読み込める3MFを優先する。不要な代替部品・角度・アダプタ・専用ゲージ・ZIPの水増しはしない。実印刷や現物評価は別検収。

## 1. 相互関係の具体化｜現物との接触・固定が必要な場合の実測

1. **接合相手を分けて確認**：壁側／ホルダー側、金属金具／樹脂枠、表／裏、厚い端／薄い端、上／下。どこに板を置くか図または文章で一致させる。隙間埋めが目的なら、貫通穴が**本当に要るか**を検討し、不要なら無孔を原則にする。
2. **最小撮影セット**：①対象面にほぼ正対し、同じ平面にmm目盛りを置いた全体写真、②厚さ・段差・ネジ頭／工具の空間が分かる斜めまたは側面写真。穴の両端・縁・部品境界・天地の目印を含める。必要な1点が不明な時だけ追加撮影を求める。複数写真の遠近法を無補正で結合しない。
3. **測る項目**：外枠の有効幅・高さ、隙間の実寸、穴の**個数と形状**、長穴の中心線・端位置・幅・方向、穴と端面の距離、ネジ径・頭／座金・ナット外形と厚み、工具の差し込み方向、干渉物。測定可能なら縁―縁や中心―中心を別々に記録する。
4. **穴位置は「ピッチ」だけでは不足**。壁側も製品側も**同一基準原点・同一向き**で各穴・各長穴の座標と占有範囲を表にする（例 `W1,W2,W3` と `H1,H2`）。写真に3穴見えれば3穴として記録し、便宜的に2穴へ間引かない。使う穴の組だけ後段で選ぶ。未確認のピッチを確定値として使わない。
5. **印刷ゲージは既定で禁止**：単なる穴間距離・全長測定のためだけに印刷させない。ものさしと写真、必要なら紙への実寸線・CAD上の寸法線で照合。どうしても曲面・届かない位置等で不可欠なら、理由と代替不可を述べて本人判断を仰ぐ。

測定表（各案件の内部ワークシート、公開しない）：`部品／面／基準原点／穴ID／中心(x,y)／長穴の端点・幅／頭・ナット・工具占有範囲／寸法値／実測・推定・未確認／写真根拠`。未確認のまま設計を進める場合は、可逆な試作として危険がない範囲に限定する。

## 2. 相互関係の具体化｜ねじ等で固定する場合の成立検証

**2枚の板の寸法を別々に正しく作っても、重ねた状態でネジが通らなければ失格。** 穴配置については次の順序を守る。

1. **共通座標化**：基準を壁の取付面等に固定して、壁穴集合 W と製品穴集合 H を同じ紙面へ投影。向き・上下・左右、取付方向、必要な回転・傾斜を明記する。紙面上に「Wの全穴」と「Hの全穴（長穴は線分＋幅）」を同時表示する。
2. **実在する対応を選択**：壁の2穴／3穴と製品の2長穴など、現物の全候補から、ネジが**実際に通る組**を選ぶ。中心線の距離だけでなく、長穴の有効範囲・必要な座金・ネジ軸の方向・穴同士の立体干渉を調べる。**「片側の穴を壁の2穴間へ入れる」等の指示は、中心が内側という数値だけではPASSにならない。可動域内で実際に締結できる位置まで確認する。**
3. **重なり図の人間可読チェック**：少なくとも平面の穴配置オーバーレイと、傾斜・厚さを含む側面断面を作る。採用した穴番号、ネジの貫通経路、ナットへの到達を寸法付きで示し、周囲と干渉しないことを確認する。画像は**モデルから導出**し、モデルと異なる手描きイメージを実体証拠と呼ばない。
4. **ねじ・工具・強度**：ネジ長は固定する板厚、締付け部品厚、座金、ナットの必要噛合い長から求める。単に楔の最大厚を貫通させる設計にしない。ナットの外形・ソケット／レンチ空間と手順を確保し、**仮組み→ねじ挿入→工具で回転→所定位置へ締付け→取り外し**の各段階に手・工具が入ることを確認する。相手のナット径が不明なら「余裕確保した仮設計」として扱う。不要なナット保持アダプタは追加しない。長穴が端に近すぎて肉厚や荷重経路を失わないことを確認する。
5. **反転・左右共用**：180°回転／鏡像が要件なら、変換後の穴対応だけでなく楔角度・上下・使える工具方向・ネジ軸の向きも再計算する。「回せるから左右共用」は禁止。成立しなければ左右別部品へ分けるか設計を戻す。

**傾斜楔の特則**：ホルダー側の「一定5mm」などの指定は、**傾斜した接合面に対する法線方向の厚み**を寸法線で定義する。切欠きの天井と接合斜面の法線が一致／平行であることをCAD幾何で検証する。印刷の積層方向Zや壁に対する鉛直厚と混同しない。5mmと指定された厚みがメッシュで4.9mm等になったらFAIL。傾斜の符号・向きが設置位置と一致しないなら角度そのものが正しくてもFAIL。

## 3. 形状生成と最短の試作

1. **固定パラメータと可変パラメータを分離**：穴数・各穴座標・長穴幅、隙間、肉厚、傾斜角、接触面、ナット包絡域、角丸を名前付きの値にする。実測と推定に注釈を付け、版と組付け向きを保持する。推定した穴ピッチのような便利な数字を他の版へコピーしない。
2. **CADの形状を評価**：部品同士の位置合わせ、干渉、底面・天井・肉厚、ネジの連続した通路、閉じた立体、非多様体、寸法と方向を確認する。2D投影図で成立しても3Dで軸が斜めに貫通しない場合があるため両方確認。組み合わせ物では完成姿勢だけでなく途中の組立・回転・スライドの経路を検査し、製造誤差を見込んだクリアランスも区別する。
3. **最小の試作品**：用途に適う1案を基本とし、本人が指定した複数角度・数量だけ同梱。3mm厚の小片3本を並べるなど現物試験で適合した構成は、理由がなければ勝手に一体化しない。改善案を増やす前に「今のままで困るか」を確認する。
4. **製造条件**：素材候補、ノズル径、積層厚、肉厚／充填、造形向き、サポート要否、A1 mini等の実際の造形範囲、剛性・積層剥離・湿気・温度の制約を対象に応じて確認する。材料による保持力・設計強度を推測で保証しない。
5. **派生ファイル検査**：CADからSTL・3MFを生成し、すべてのパーツ数、単位mm、バウンディングボックス、法線、閉鎖メッシュ、重複・床浮き・造形範囲を確認。3MFはファイル名だけでなく中身が有効な3MFであること、指定スライサーで読めることを可能な範囲で確認する。実際にBambu Studioで開いていなければ「開けた」はNOT_RUN。サポート／材料／品質の設定が3MFに入っているか、利用者側指定が必要かを明記。
6. **出力の受渡し**：推奨ファイル1つ、編集用ソース、必要な比較図（上面穴配置＋断面）を分かりやすく渡す。ZIPは複数ファイルが必要な時のみ。保存された実ファイルの実在・サイズ・読み直しをチェックする。リンクを表示しただけでダウンロード完了とは扱わない。

## 4. 選択した設計観点に応じた品質確認（不要な全ゲートは適用しない）

G0〜G8は**②相互関係のうち、ねじ等を使って現物に固定する場合の厳密な品質検査**として保持する。G2（全穴の同一座標・ねじ経路）とG3（ナット・工具等）をゲーム小物やCGへ一律適用しない。**組み合わせる造形物では別の新ゲートを増やさず**、G5の幾何検査で必要な相対姿勢・組立経路・すき間・保持を対象にし、G8に相当する実物評価は印刷後のみとする。G8は実物の組付け・用途適合を本人が確認した時にのみ判定する。それ以外は①形状・構造、②必要な相互関係、③意匠・表現、④製造・利用の該当項目だけを確認する。該当しない項目はN/A、未実施はNOT_RUNとする。


| ID | 検査対象 | PASS条件と検査方法 | FAIL時 |
|---|---|---|---|
| G0 | 要件・置き場所 | 取付位置、接触する2部品、用途、保持する条件と禁止形状を短文と図で一致させた | 図解に戻り、無断で穴を足さない |
| G1 | 元寸法 | 穴数・穴方向・端面距離・肉厚・隙間、実測／推定／未確認を区別し、写真内のmm目盛り等で根拠を確認した | 数字の推測を確定せず、必要な1箇所だけ再測定 |
| **G2** | **穴位置の重ね合わせ** | **壁・製品の全穴を同一座標に投影。選んだ対応のネジ通路・有効長穴範囲・相互距離・材料縁・斜め軸を確認。指示された「内側配置」を実組付けで満たす** | **CAD出力を停止。元の座標・取付向きを見直す** |
| G3 | 断面・組付け | 指定厚みを接合面法線で測定、ナット・座金・工具・ネジ長・周囲との干渉を確認 | 薄肉・片側の長ネジ要求・アクセス不能を修正 |
| G4 | 変更差分 | 以前確定した穴・左右・角度・素材・部品数・不要部品禁止が保持され、今回の指摘以外が変わっていない | 影響差分のみ再設計し変更一覧を更新 |
| G5 | CAD／メッシュ | 非空、閉じた立体、法線と単位、外寸・角度・穴数・連通、パーツ数を直接検査 | FAILを直して再生成 |
| G6 | スライサー互換 | 3MFを実際に開いて造形範囲・向き・支持・各部品を確認。実行できない検査はNOT_RUN | 未検証をPASSに格上げしない |
| G7 | 受渡し | 現行の版と形式・リンク／保存先・編集原本・必要図が一致し、保存後に読戻せた | 再作成か取得可能な代替形式に変更 |
| G8 | 現物適合 | 実際の印刷物で穴整合、組付け、ネジと工具、ズレ、目的の動作を利用者が確認 | 実物確認まではQ4=NOT_RUN |

**組付け実用品のみの出力停止線**：実測不足で複数穴の対応が決められない、G2を満たせない、ねじ固定の安全・落下リスクに重大な不明点がある場合は「完成」として3MFを提出せず、どの座標／写真の1点が必要かを伝える。実測不能でも危険がなく可逆な寸法検証の候補モデルを出す場合は、**試験用・適合未確認**を明記し完成扱いしない。G5だけ通ってG2がFAILしたモデルは**不合格**。

共通標準の4階層：Q1=手順の記述品質、Q2=別AI/初見作業者の解釈、Q3=ソフトでの実生成と検査、Q4=実際の印刷・用途適合。自身による3回の校正はQ2独立試験ではない。合格項目・未実施項目を混同せず PASS/FAIL/NOT_RUN/N/A で記録する。

## 5. 人間への依頼・修正の運び方

利用者に求めるのは原則**ものさし1本でできる最短測定**。既出の写真・数字を再提出させず、必要な「穴W2の中心から右端まで」等の1点だけ質問。人間の作業が3工程以上の時だけ全体工程と現在地を短く表示する。ユーザーが図面に疑問を述べたら、**説明図だけの問題と、実CADの問題を別々に実検査**し、見た目で安全宣言しない。

**同じ不適合を2回指摘されたら**、仮パラメータの小変更を止め、目的・接合面・穴の基準座標・使う穴の組み合わせから再検討する。失敗モデルのリンクを新しい完成版として再利用しない。変更後は再発部分と依存する部分だけ再検査する。旧版の角度や不要なナットアダプタを勝手に復活させない。

本人への最後の提示順は、**使うファイル→改訂点（最大3点）→実際にPASSした検査／NOT_RUN→現物で見るべき1点**。実際に測定していない推定サイズや、ツール未実行の動作を「検査済み」にしない。

## 6. 実例と教訓（数値を他案件の標準値にしない）

### 実例A：①形状・構造＋②固定の相互関係＋④利用（トイレットペーパーホルダー傾斜アダプタ）
- 実在する壁側・ホルダー側の穴、長穴、ネジ軸、ナットと工具空間を使って、紙を取りやすい方向へ角度を付ける実用品。既存のG2/G3に記録済みの**穴数・穴ピッチを合わせただけでは実装できない**失敗が実際の知見。
- 壁穴・ホルダー穴を同じ原点・方向へ投影し、使える長穴の範囲、締結時のネジ長、ナット到達、工具が入る空間まで含める。寸法があるだけでは適合判定にならない。
- 初期の5°・10°などの案を経て、**本人がV10・15°版を採用・設置したと2026-10-30に報告**した経緯を保存する。これは本人の現物評価であり、当該CADを今回再測定・再読込したという意味ではない。採用角度やネジ寸法を他製品の標準として流用しない。
- **最短の学び**：必要な接触面とネジ通路だけを測り、ものさし＋写真で照合。不要なゲージ・別アダプタ・追加形式を作らず、既に合った試作品を維持する。実物への組付け成功とSTLの正常性は別検査。
- 家庭固有の写真・個人の所在地・非公開素材・取付先識別子は共有Playbookに持ち込まない。

### 実例B：①形状・構造＋②嵌合の相互関係＋③意匠・表現（直径95mmのダイストレイ）
- 外周の28柱を噛み合わせる用途では、2個の反転・半ピッチ回転、柱の幅、スリットが**どの面からどこまで開くか**、内側に残す床を別々の幾何条件として定義する。完成位置での非干渉に加え、**2個を噛み合わせていく途中の経路と取り外しやすさ**も必要な条件である。「貫通」と言っても中央床の穴まで認めるものではない。
- 丸柱・方形柱や柱装飾の比較では、**本人の確定部分（柱数、収納機能、ボウル面）を固定**して変える。柱が主役なら縦溝、外周が主役なら幾何帯のように、装飾する面自体を設計変数にする。
- 印刷物で実際に柱先端が引っ掛かったため、**内側先端のRとスリット深さを局所修正し、柱を根元から頂点まで連続させる**改訂を行った。新規モデルの幾何上の非干渉は現物での成功と同義ではない。ケルト四本編みは周期曲線・交点の上下交換、雷文は矩形格子から円周展開→3Dへ写像。しっかりした文様なら数式と反復数を持たせる。完成イメージだけで3Dメッシュへの刻印完了とは言わない。
- 底面裏のロゴで**左右鏡像**、文様で**凹凸の逆**、収納スリットで**深さ／連通の誤解**を経験した。表裏・断面・反転収納を実STLから確認し、問題箇所だけ直す。
- **2026-11-18の現物フィードバック**：本人がv21を実際に印刷し、2個を開いた状態と反転収納した状態の写真を提示。**実物が作れ、2個を重ねられたこと**まで確認した（モデルの計算上の検査とは別の実証）。ただし、抜き差しに必要な力・繰り返し耐久・ロゴ細部の可読性は測定していない。v21固有の柱厚6.5mm・先端R2.55mm・上部内面の逃げ0.36mmを、他モデルの既定値にはしない。失敗→最小修正→現物再試験の知見を共有することで、次の人とAIは同じ誤りの再発防止から始められる。
- 実STLの水密や干渉チェックと、実印刷・ダイス保持・噛み合わせは別判定。95mm・28柱等は当該案件固有の値。

## 7. 代表的な失敗への回帰試験

| ケース | 合格する実行解釈 |

| R1「金具と樹脂枠の中」「横ずれ止め」「穴不要」 | 金具のネジ穴を真似た穴あき板ではなく、接触面を埋める無孔スペーサーを提案 |
| R2 3mm厚の細長い小片を3本並べて現物適合 | 実際の並びと合計幅を測定して記録し、未依頼の一体化・追加ゲージ印刷をしない |
| R3 壁側に3つ、ホルダー側に2つの長穴が見える | 壁穴を2穴と決めつけずW1〜W3、H1〜H2の対応を決めてG2を通す |
| R4 壁76mm、ホルダー108mmという2数値が既知 | ピッチだけで穴座標・組付け可否を決めない。原点／向き／オフセット／長穴の可動域を実測する |
| R5「片側の斜め穴が壁の穴の間に入らないと届かない」 | 数値上の中心位置だけでなく、実際に使う穴の組・ネジ軸・ナット到達をオーバーレイと断面で証明 |
| R6 楔の斜面に垂直な厚み5mm指定 | 断面上の法線距離を5.0mmにし、4.9mmならFAIL。ネジ長が左右一定で済むことを別途確認 |
| R7「ナットアダプタは不要」「ナットサイズが不明」 | アダプタを削除し、ナット・工具の空間は余裕を持たせつつ未確定と表示 |
| R8 10°・15°、左右共用 | 指定の2角度だけ生成。反転後も傾斜方向・穴の組・工具が成立するか変換後のG2/G3を確認 |
| R9 STL/3MFは正常、現物でネジが届かない | G5=PASSでもG2/G3=FAIL、Q4=FAIL。適合前の「完成」宣言を止める |
| R10 測定写真が斜めで穴中心が判読できない | 画像だけで確定ピッチを捏造せず、必要な1点の測定を要求。ゲージ印刷は要求しない |
| R11 穴位置は一致するが工具が回せない | ネジ頭・ナット・座金と工具の進入・回転・締付け手順を3Dで点検。「ねじが通る」だけでは適合としない |
| R12 2部品の完成位置は干渉ゼロだが途中で引っかかる | 組立開始から完成までの挿入・回転・スライドの経路を点検し、すき間／面取り／公差を対象に応じ数値化する |
| R13 スリットが深いが必要な床まで貫通した／浅くて組めない | 「どの面を貫通させ、どの面に残肉を必要とするか」を断面・裏面で検証。作品固有の開口条件に従う |
| R14 組み合わせ装飾のロゴが裏返る／彫刻が接触面に突出する | 組立・反転後の視点で可読方向と凹凸を確認し、嵌合面のクリアランスを侵さない |
| R15 組み合わせる柱の先端内側が引っ掛かり、スリットも柱の実占有深さに足りない | 先端R・入口の案内形状とスリットの径方向深さ・幅を数値化し、**完成姿勢までの挿入経路**で干渉を再検査。実印刷と収納成功は版ごとに別判定する（実例Bのv21は2026-11-18に本人の実印刷・反転収納を確認済み） |
| R16 一本の柱なのに途中の段差が残る／指定3本の縦溝が増減する／採用済ロゴを落とす | 一本の連続形状か、溝の本数・位置・深さが指定どおりか、ロゴの有無・底面の正読・反転を実STLで確認。確認済み部分を勝手に破棄しない |
