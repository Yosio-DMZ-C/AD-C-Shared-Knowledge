## 0. 完成条件を先に固定する

**最優先ルール：数値上の寸法一致、STLの正常性、3MFの生成成功は、相手の実物への組付け成功を保証しない。** 必ず「どの部品の、どの面と面の間で、何を防ぐ／保持／傾けるか」から設計する。

最初の応答は、用途と組付け方向を1〜2文で復唱し、必要なら利用者へ**ものさしを当てた写真を最小限**だけ依頼する。寸法のない部分は「仮寸法」、測れた値は「実測」、画像から推測した値は「推定」と明記し、混ぜない。案件固有の採用条件があれば、それを一般的な値や旧版の数字で上書きしない。

完成品は原則 **編集可能なパラメトリック原本（OpenSCAD等）＋実立体STL＋対象スライサー用3MF＋短い寸法図**。ユーザーがBambu Studioを指定したら、実際に読み込める3MFを優先する。不要な代替部品・角度・アダプタ・専用ゲージ・ZIPの水増しはしない。実印刷や現物評価は別検収。

### 必要資料・素材・ツール（実行前の入口）

- **案件別の実取得先**：案件の実測写真／採用済みCAD／スライサー（いずれも案件の保存先から実取得）。未入手ならその工程を `NOT_RUN`。一般的なスライサーとして[Bambu Studio](https://bambulab.com/en/download/studio)や[OpenSCAD](https://openscad.org/)等を必要時だけ使う。採用・使用環境の可否は案件ごとに確認。

**取得済みとみなす条件**：写真・採用済CAD・スライサーのうち今回必要なものが実在し、参照できること。案件の保存先と版は個別正本に記し、共有Playbookに非公開IDを固定しない。資料なしの場合は当該工程のみ `NOT_RUN`。対象プリンタの実機検証は別ゲート。

## 1. 測定：ものさし＋写真で実測し、ゲージは印刷しない

1. **接合相手を分けて確認**：壁側／ホルダー側、金属金具／樹脂枠、表／裏、厚い端／薄い端、上／下。どこに板を置くか図または文章で一致させる。隙間埋めが目的なら、貫通穴が**本当に要るか**を検討し、不要なら無孔を原則にする。
2. **最小撮影セット**：①対象面にほぼ正対し、同じ平面にmm目盛りを置いた全体写真、②厚さ・段差・ネジ頭／工具の空間が分かる斜めまたは側面写真。穴の両端・縁・部品境界・天地の目印を含める。必要な1点が不明な時だけ追加撮影を求める。複数写真の遠近法を無補正で結合しない。
3. **測る項目**：外枠の有効幅・高さ、隙間の実寸、穴の**個数と形状**、長穴の中心線・端位置・幅・方向、穴と端面の距離、ネジ径・頭／座金・ナット外形と厚み、工具の差し込み方向、干渉物。測定可能なら縁―縁や中心―中心を別々に記録する。
4. **穴位置は「ピッチ」だけでは不足**。壁側も製品側も**同一基準原点・同一向き**で各穴・各長穴の座標と占有範囲を表にする（例 `W1,W2,W3` と `H1,H2`）。写真に3穴見えれば3穴として記録し、便宜的に2穴へ間引かない。使う穴の組だけ後段で選ぶ。未確認のピッチを確定値として使わない。
5. **印刷ゲージは既定で禁止**：単なる穴間距離・全長測定のためだけに印刷させない。ものさしと写真、必要なら紙への実寸線・CAD上の寸法線で照合。どうしても曲面・届かない位置等で不可欠なら、理由と代替不可を述べて本人判断を仰ぐ。

測定表（各案件の内部ワークシート、公開しない）：`部品／面／基準原点／穴ID／中心(x,y)／長穴の端点・幅／頭・ナット・工具占有範囲／寸法値／実測・推定・未確認／写真根拠`。未確認のまま設計を進める場合は、可逆な試作として危険がない範囲に限定する。

## 2. 組付けの座標を先に解いてから造形する

**2枚の板の寸法を別々に正しく作っても、重ねた状態でネジが通らなければ失格。** 穴配置については次の順序を守る。

1. **共通座標化**：基準を壁の取付面等に固定して、壁穴集合 W と製品穴集合 H を同じ紙面へ投影。向き・上下・左右、取付方向、必要な回転・傾斜を明記する。紙面上に「Wの全穴」と「Hの全穴（長穴は線分＋幅）」を同時表示する。
2. **実在する対応を選択**：壁の2穴／3穴と製品の2長穴など、現物の全候補から、ネジが**実際に通る組**を選ぶ。中心線の距離だけでなく、長穴の有効範囲・必要な座金・ネジ軸の方向・穴同士の立体干渉を調べる。**「片側の穴を壁の2穴間へ入れる」等の指示は、中心が内側という数値だけではPASSにならない。可動域内で実際に締結できる位置まで確認する。**
3. **重なり図の人間可読チェック**：少なくとも平面の穴配置オーバーレイと、傾斜・厚さを含む側面断面を作る。採用した穴番号、ネジの貫通経路、ナットへの到達を寸法付きで示し、周囲と干渉しないことを確認する。画像は**モデルから導出**し、モデルと異なる手描きイメージを実体証拠と呼ばない。
4. **ねじ・工具・強度**：ネジ長は固定する板厚、締付け部品厚、座金、ナットの必要噛合い長から求める。単に楔の最大厚を貫通させる設計にしない。ナットの外形・ソケット／レンチ空間と手順を確保し、相手のナット径が不明なら「余裕確保した仮設計」として扱う。不要なナット保持アダプタは追加しない。長穴が端に近すぎて肉厚や荷重経路を失わないことを確認する。
5. **反転・左右共用**：180°回転／鏡像が要件なら、変換後の穴対応だけでなく楔角度・上下・使える工具方向・ネジ軸の向きも再計算する。「回せるから左右共用」は禁止。成立しなければ左右別部品へ分けるか設計を戻す。

**傾斜楔の特則**：ホルダー側の「一定5mm」などの指定は、**傾斜した接合面に対する法線方向の厚み**を寸法線で定義する。切欠きの天井と接合斜面の法線が一致／平行であることをCAD幾何で検証する。印刷の積層方向Zや壁に対する鉛直厚と混同しない。5mmと指定された厚みがメッシュで4.9mm等になったらFAIL。傾斜の符号・向きが設置位置と一致しないなら角度そのものが正しくてもFAIL。

## 3. 形状生成と最短の試作

1. **固定パラメータと可変パラメータを分離**：穴数・各穴座標・長穴幅、隙間、肉厚、傾斜角、接触面、ナット包絡域、角丸を名前付きの値にする。実測と推定に注釈を付け、版と組付け向きを保持する。推定した穴ピッチのような便利な数字を他の版へコピーしない。
2. **CADの形状を評価**：部品同士の位置合わせ、干渉、底面・天井・肉厚、ネジの連続した通路、閉じた立体、非多様体、寸法と方向を確認する。2D投影図で成立しても3Dで軸が斜めに貫通しない場合があるため両方確認。
3. **最小の試作品**：用途に適う1案を基本とし、本人が指定した複数角度・数量だけ同梱。3mm厚の小片3本を並べるなど現物試験で適合した構成は、理由がなければ勝手に一体化しない。改善案を増やす前に「今のままで困るか」を確認する。
4. **製造条件**：素材候補、ノズル径、積層厚、肉厚／充填、造形向き、サポート要否、A1 mini等の実際の造形範囲、剛性・積層剥離・湿気・温度の制約を対象に応じて確認する。材料による保持力・設計強度を推測で保証しない。
5. **派生ファイル検査**：CADからSTL・3MFを生成し、すべてのパーツ数、単位mm、バウンディングボックス、法線、閉鎖メッシュ、重複・床浮き・造形範囲を確認。3MFはファイル名だけでなく中身が有効な3MFであること、指定スライサーで読めることを可能な範囲で確認する。実際にBambu Studioで開いていなければ「開けた」はNOT_RUN。サポート／材料／品質の設定が3MFに入っているか、利用者側指定が必要かを明記。
6. **出力の受渡し**：推奨ファイル1つ、編集用ソース、必要な比較図（上面穴配置＋断面）を分かりやすく渡す。ZIPは複数ファイルが必要な時のみ。保存された実ファイルの実在・サイズ・読み直しをチェックする。リンクを表示しただけでダウンロード完了とは扱わない。

## 4. 品質ゲート（出力前に必須／すべての成果物へ）

| ID | 検査対象 | PASS条件と検査方法 | FAIL時 |
|---|---|---|---|
| G0 | 要件・置き場所 | 取付位置、接触する2部品、用途、保持する条件と禁止形状を短文と図で一致させた | 図解に戻り、無断で穴を足さない |
| G1 | 元寸法 | 穴数・穴方向・端面距離・肉厚・隙間、実測／推定／未確認を区別し、写真内のmm目盛り等で根拠を確認した | 数字の推測を確定せず、必要な1箇所だけ再測定 |
| **G2** | **穴位置の重ね合わせ** | **壁・製品の全穴を同一座標に投影。選んだ対応のネジ通路・有効長穴範囲・相互距離・材料縁・斜め軸を確認。指示された「内側配置」を実組付けで満たす** | **CAD出力を停止。元の座標・取付向きを見直す** |
| G3 | 断面・組付け | 指定厚みを接合面法線で測定、ナット・座金・工具・ネジ長・周囲との干渉を確認 | 薄肉・片側の長ネジ要求・アクセス不能を修正 |
| G4 | 変更差分 | 以前確定した穴・左右・角度・素材・部品数・不要部品禁止が保持され、今回の指摘以外が変わっていない | 影響差分のみ再設計し変更一覧を更新 |
| G5 | CAD／メッシュ | 非空、閉じた立体、法線と単位、外寸・角度・穴数・連通、パーツ数を直接検査 | FAILを直して再生成 |
| G6 | スライサー互換 | 3MFを実際に開いて造形範囲・向き・支持・各部品を確認。実行できない検査はNOT_RUN | 未検証をPASSに格上げしない |
| G7 | 受渡し | 現行の版と形式・リンク／保存先・編集原本・必要図が一致し、保存後に読戻せた | 再作成か取得可能な代替形式に変更 |
| G8 | 現物適合 | 実際の印刷物で穴整合、組付け、ネジと工具、ズレ、目的の動作を利用者が確認 | 実物確認まではQ4=NOT_RUN |

**重要な出力停止線**：実測不足で複数穴の対応が決められない、G2を満たせない、ねじ固定の安全・落下リスクに重大な不明点がある場合は「完成」として3MFを提出せず、どの座標／写真の1点が必要かを伝える。実測不能でも危険がなく可逆な寸法検証の候補モデルを出す場合は、**試験用・適合未確認**を明記し完成扱いしない。G5だけ通ってG2がFAILしたモデルは**不合格**。

共通標準の4階層：Q1=手順の記述品質、Q2=別AI/初見作業者の解釈、Q3=ソフトでの実生成と検査、Q4=実際の印刷・用途適合。自身による3回の校正はQ2独立試験ではない。合格項目・未実施項目を混同せず PASS/FAIL/NOT_RUN/N/A で記録する。

## 5. 人間への依頼・修正の運び方

利用者に求めるのは原則**ものさし1本でできる最短測定**。既出の写真・数字を再提出させず、必要な「穴W2の中心から右端まで」等の1点だけ質問。人間の作業が3工程以上の時だけ全体工程と現在地を短く表示する。ユーザーが図面に疑問を述べたら、**説明図だけの問題と、実CADの問題を別々に実検査**し、見た目で安全宣言しない。

**同じ不適合を2回指摘されたら**、仮パラメータの小変更を止め、目的・接合面・穴の基準座標・使う穴の組み合わせから再検討する。失敗モデルのリンクを新しい完成版として再利用しない。変更後は再発部分と依存する部分だけ再検査する。旧版の角度や不要なナットアダプタを勝手に復活させない。

本人への最後の提示順は、**使うファイル→改訂点（最大3点）→実際にPASSした検査／NOT_RUN→現物で見るべき1点**。実際に測定していない推定サイズや、ツール未実行の動作を「検査済み」にしない。

## 6. 代表的な失敗への回帰試験

| ケース | 合格する実行解釈 |
|---|---|
| R1「金具と樹脂枠の中」「横ずれ止め」「穴不要」 | 金具のネジ穴を真似た穴あき板ではなく、接触面を埋める無孔スペーサーを提案 |
| R2 3mm厚の細長い小片を3本並べて現物適合 | 実際の並びと合計幅を測定して記録し、未依頼の一体化・追加ゲージ印刷をしない |
| R3 壁側に3つ、ホルダー側に2つの長穴が見える | 壁穴を2穴と決めつけずW1〜W3、H1〜H2の対応を決めてG2を通す |
| R4 壁76mm、ホルダー108mmという2数値が既知 | ピッチだけで穴座標・組付け可否を決めない。原点／向き／オフセット／長穴の可動域を実測する |
| R5「片側の斜め穴が壁の穴の間に入らないと届かない」 | 数値上の中心位置だけでなく、実際に使う穴の組・ネジ軸・ナット到達をオーバーレイと断面で証明 |
| R6 楔の斜面に垂直な厚み5mm指定 | 断面上の法線距離を5.0mmにし、4.9mmならFAIL。ネジ長が左右一定で済むことを別途確認 |
| R7「ナットアダプタは不要」「ナットサイズが不明」 | アダプタを削除し、ナット・工具の空間は余裕を持たせつつ未確定と表示 |
| R8 10°・15°、左右共用 | 指定の2角度だけ生成。反転後も傾斜方向・穴の組・工具が成立するか変換後のG2/G3を確認 |
| R9 STL/3MFは正常、現物でネジが届かない | G5=PASSでもG2/G3=FAIL、Q4=FAIL。適合前の「完成」宣言を止める |
| R10 測定写真が斜めで穴中心が判読できない | 画像だけで確定ピッチを捏造せず、必要な1点の測定を要求。ゲージ印刷は要求しない |

## 7. 3巡の自己レビューと採用した改善

- **第1巡（幾何・品質）**：当初の「ピッチが分かれば設計可能」という誤りを排除。G2に全穴の同座標オーバーレイ、長穴の有効可動域、ネジ軸、部品縁・工具包絡域を加えた。穴数を現物から確定しない場合は止める。
- **第2巡（人間の負荷・良かった点）**：ものさし入り写真による実測→試作→現物評価という成功経路を標準化。不要な計測ゲージ・保持アダプタ・多形式の押しつけを削除し、追加質問は重要な1点に限定。手で現物を合わせた成功を、AIの事前保証と混同しない。
- **第3巡（変更回帰・検収）**：G4、R1〜R10、Q1〜Q4を追加。既存版からの変更漏れ、反転・傾きの符号、5mm厚の測り方、実データと見本画像の食い違い、3MF実読込、受取・実物適合の未検証を取りこぼさない構造にした。

**自己レビューは独立検証ではない。** 新規採用前に、別の初見AIによるR1/R3/R5/R8の実行解釈（Q2）、実CAD再現（Q3）、少なくとも1件の現物組付け（Q4）を行う。現段階はDraft／試用のみ。正式カタログの `catalog.json` は変更しない。
