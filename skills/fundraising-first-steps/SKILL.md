## 【目的】

お金や専門家の知識が足りない個人のアイデアが、資金調達の仕組みを知らないために諦められないよう、**自分の企画を1枚に整理し、適切な支援方法を選び、契約前に必要な確認まで進める**。

## 【背景】

- **対象**：創作、ものづくり、イベント、地域事業など、実現したい企画がある個人・小規模チーム。
- **狙い**：最初からエンジェル投資家との人脈や有料コンサルがなくても、実現可能性を説明し、必要な資金と相手への約束を整理できるようにする。
- **位置づけ**：AD&Cは資金を仲介・募集・保証しない。AIは準備と比較を手伝い、契約とリスクの判断は本人と適格な専門家が行う。

## この手順が適用できる場合・できない場合

**使える**：企画がアイデア段階〜初期実証段階で、まだ誰に何を頼めばよいか整理できていないとき。

**この手順だけでは対応しない**：株式や新株予約権の発行の実行、投資勧誘や仲介、契約書の法的判断、税務申告、相手方への投資勧誘文の一斉送信、保証付きリターンの約束、他人の出資金管理。これらは制度と専門家の確認を経る。未成年・法人化前・個人事業で使える資金調達手段は異なるため、契約の前に主体と適用条件を確認する。

## 最初の1操作：企画を1枚にまとめる

AIまたは紙のメモに以下の6欄を埋める。未確定なら「未定」でよい。

| 項目 | 書くこと |
|---|---|
| 1. 誰のどんな問題か | 既にある困りごと、対象となる人 |
| 2. 何を作るか | 作品、イベント、サービスなど具体的な成果 |
| 3. 小さく試した証拠 | 試作品、反応、参加希望者、実施例（なければ未実証） |
| 4. 必要なお金 | 必要総額、費目、いつまでに必要か、自己負担分 |
| 5. 支援する人への約束 | 返礼、商品、寄付の目的、返済、持分など。未確定なら約束しない |
| 6. 失敗したとき | 中止条件、返金・返済・持分の扱い、未達時の連絡方法 |

**完了条件**：第三者が読んで「何を実現し、いくら必要で、失敗すると何が起こるか」を説明できる。企画の優劣や成功率をAIが保証したことにはしない。

## 最初の分岐：欲しいのは本当に「投資」か？

| 方式 | 何を渡す・返すか | 初期確認 |
|---|---|---|
| 予約販売・購入型クラウドファンディング | 将来の商品・参加権・返礼品など | 納期、費用、返金条件、実現可能性。株式を渡すものではない |
| 協賛・スポンサー | 広告、ロゴ掲載、冠協賛などの対価 | 広告権利、成果の約束、表示内容、契約主体 |
| 寄付・助成金 | 制度に沿った寄付または採択資金 | 募集資格、使途、報告義務、返還条件。自由に使えるとは限らない |
| 融資 | 元本返済と利息などの義務 | 返済原資、資金繰り、契約条件、保証の有無 |
| **株式出資・エンジェル投資** | 会社の持分、投資契約に基づく権利 | 法人格、評価額、希薄化、経営権、投資家の権利、出口戦略 |
| J-KISS等の転換型の投資 | 取り決めに従い、将来の資金調達時などに株式へ転換する権利 | 転換条件、上限評価額・割引などの契約条件、専門家による確認 |

**重要**：「誰かからお金を受け取る」＝「投資を受ける」ではない。返礼・出資・融資・寄付は、約束と責任が異なる。無償支援を装った返済約束や、確実な利益を保証する表現をしない。

## 企画者の最短手順（準備〜面談）

1. **1枚の企画書**を作る。6欄を埋め、概算費用と使途を見えるようにする。イベントなら会場費、出演者・制作費、保険、広報費、キャンセル時の費用も確認する。
2. **最小実証**を一つ行う。試作品、少人数の催し、利用者の意見など。まだないなら「未実証」のまま相談できるようにする。
3. **まず資金の性格を決める**。少額・単発イベントなら予約販売や協賛が合う場合があり、株式を渡さず実施できる選択肢も比較する。株式投資を第一選択に固定しない。
4. **相手を探す前に説明の準備をする**。紹介を頼む相手へのメッセージは「何を実現したいか／誰に価値があるか／今回何を相談したいか／1枚資料」まで。未承認の出資勧誘や投資条件の公開・大量送信をAIに任せない。
5. **相手との面談では条件を記録**。金額だけでなく、意思決定権、情報開示、返済・払戻し、未達時の処理、次の資金調達への影響も書く。
6. **契約・着金前の停止ゲート**。株式・新株予約権・投資勧誘・個別税務・権利関係・融資契約を伴う場合、現行制度と弁護士・税理士等の適格な専門家を確認し、本人が条件を理解して承認する。契約を急かされたり、利益保証・名義貸し・不明な送金先が現れたら一旦停止する。

確認日：2026-11-05。制度の改正・適用時点・個別要件は各公式ページの最新版を取って確認する。

- [国税庁｜エンジェル税制の概要](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1544.htm)：税務の原則と適用要件。税効果を約束しない。
- [日本政策金融公庫｜創業融資](https://www.jfc.go.jp/n/finance/search/sogyoyushi.html)：出資と区別すべき融資・返済の検討。
- [日本政策金融公庫｜創業計画書セルフチェック](https://www.jfc.go.jp/n/finance/sougyou/sougyouselfchek/)：資金の使い道と事業計画の整理。

- [Coral Capital｜J-KISS](https://coralcap.co/j-kiss/)：民間公開の契約ひな形と説明。**公的機関の承認済み契約という意味ではない**。利用時は契約条件を専門家に確認する。

## AIに渡す短い依頼文

```text
私は企画を実現するための資金を集めたいです。最初から株式投資を前提にせず、企画・必要額・相手への約束を1枚に整理するのを手伝ってください。足りない情報は1問ずつ聞き、予約販売・協賛・助成金・融資・出資の違いを説明してください。金融商品の勧誘や契約は実行せず、必要な専門家確認と次の1行動を示してください。
```

## 完了／停止／引継ぎ

- **初回PASS**：本人が修正できる1枚企画書と、比較した資金方法、必要額・使途、次の相談相手の種類、未確認点1件が揃った。
- **実行NOT_RUN**：相手への出資勧誘、資金調達成約、契約作成・締結、法律・税務の個別確認。原稿を作っただけで着金PASSとしない。
- **停止**：公衆への投資勧誘・具体的な株式条件提示・権利譲渡・融資申込・送金・保証などの条件を本人が未確認の場合。専門家確認が必要な条件は判断せず保留。
- **引継ぎ**：企画書の最新版、選んだ調達方法、話した相手との合意・不同意、未完了の1件を本人の非公開KBに保管。実際の連絡先、投資家氏名、金額、個人情報、契約案を公開共有KBに保存しない。
