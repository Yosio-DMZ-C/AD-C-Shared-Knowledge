## 目的・適用

**既存の実歩行ルートを見つけ、希望との差分だけ安全に補い、移動手段3方式と季節装備まで一枚のワークシートで答える。** 見つかった適合ルートがあれば無目的に全サイトを検索しない。AIは地図上に登山道・通過可能な近道を創作しない。

入力：目的地・希望の現地活動時間・見どころ・難易度／同行条件・山行予定日（なければ季節）・出発地。**不足情報のために検索を止めず**妥当な仮定で開始し、結果を左右する1点だけ必要時に質問する。「約2時間」は指定がなければ現地活動（駐車場・登山口等を起点とする歩行＋見学＋休憩）と扱い、往復交通を別に示す。登山届・入山規制等の別途必要な条件は省かない。

## 実行フロー（検索を終えたら「思考と補完」に戻る）

1. **原型を採用**：同一コースの直接URL・距離・標準コースタイム・累積上り下り・起終点を取得。合致候補を最大3つ比較し原則1つ採用。直近の同季節ログがあれば路面・混雑・難所を確認。**ルートが成立した時点で他サービス検索を終了**。
2. **差分を埋める**：希望時間・見どころ・体力に足りない点を抽出し、既存の登山道上の短縮・寄り道、または下山後の電車／バス／タクシー／車移動で補う。寄り道の接続点と往復距離・登り下りを必ず確認。地図の直線・自動車道のナビ線を「登山道」とみなさない。成立しなければ別原型へ戻す。
3. **交通3方式・費用**：電車＋徒歩／電車＋バスまたはタクシー／自家用車を必ず1表で比較。復路・登山口アクセス・駐車場への帰着を含める。出発地未指定なら目的地に近い**異なる2県の県庁所在地の代表駅**を参考起点にする（例：大阪駅・奈良駅）。運賃は公式・信頼できる経路検索による確認値のみ。
4. **時間と時期**：原型の標準歩行＋追加の歩行＋見学／撮影＋休憩＋安全余裕を分離して合計。**コース上の見どころで既計上の歩行を重ねない**。通過最高標高と予定月を最初の季節分類に使い、気温・風・降水・残雪・日没・同季節の直近記録で補正して装備を決める。
5. **停止と検収**：公式の通行止め・雪氷・技術難所・復路最終便・駐車可否・下山可能時刻を確認。成立しない初心者ルートは「行ける」と推奨しない。最終出力は下のワークシートをそのまま使い、長い調査履歴を貼らない。

## ワークシート（作業中に記入 → そのまま利用者に提示）

冒頭の1行：**「確認日：YYYY-MM-DD／現地約○時間・交通別／※は距離と想定滞在からの推定。運賃・時刻・気象は変動」**。毎行に注意書きを繰り返さない。

| 欄 | 回答に残す最小の形（内部では根拠・確認状態も持つ） |
|---|---|
| **①推奨コース** | **1案**＋[実際のコースへの直接リンク]／○km・標準○分・累積上り○m／起終点。条件に合う理由を1文。目的のピーク紹介を別欄で重複しない。 |
| **②差分・行程** | 原型にない希望→どう補ったか（実在道の寄り道／下山後の別移動）。歩行○分＋寄り道○分＋見学○分＋休憩○分＋余裕○分＝**現地○分**。コースタイムの休憩込み／別を確認。 |
| **③見どころ（共通1表）** | 見どころ｜本線から片道○m（または本線上）｜立寄り追加○分※。交通方式ごとにコピーしない。 |
| **④アクセス（3方式を共通1表）** | 電車＋徒歩：**○○駅（大阪駅から○円／○分、奈良駅から○円／○分）** → 登山口徒歩○分／復路。電車＋バス／タクシー：乗継駅→登山口○円／○分、帰りの便・手配。車：**○○駐車場（○円／台・入口徒歩○分）**／発着地点の帰還可否・現地車移動。各方式にアクセス片道時間を簡記。 |
| **⑤時期・服装・装備** | **「予定月・通過最高標高○m → 季節区分（暫定）」**、一行の服装、必携装備＋条件付き装備。下表の定型句を選び、具体的な予報・残雪状況で修正。 |
| **⑥安全・実施判断** | 直近ログの季節／規制の確認日、主な難所・トイレ・水・日没前帰着・引返しの目安を**重要点だけ**。安全性が成立しない場合は代替1案または中止を結論にする。 |
| **⑦出典・未確認** | 主ルートURLと、判断が変わる公式規制・公共交通等の直接URLだけ。未確認はその項目に **NOT_RUN**、適用不能なら **N/A（理由）**。最後に1行：**「出発前に天候・現地規制・当日のダイヤ・駐車条件を再確認」**。 |

アクセス比較は片道・大人1人の公共交通費を基準にし、往復見積もりが必要なら2倍できるか（往復割・運賃制度）を確認する。車は駐車料金を1台単位とし、有料道路料金は経路指定と料金の実測がある場合だけ記載。燃料費を根拠なしで付けない。出発地が未指定で遠方の車移動時間を計算できなければ「出発地未指定」と表示。存在しない便・タクシー営業・駐車場を作らない。

### 見どころの追加時間：唯一の計算規則

- **本線上**＝その場所での見学・撮影時間だけ（原型の歩行分を足し直さない）。
- **本線外**＝本線との接続点からの**往復実歩行距離 ÷ 適用可能な歩行速度 ＋ 見学時間**。登り下りや岩場があれば標高差・既存コースタイムで補正し、平坦距離だけの計算を使わない。
- 推定した追加時間に**※**を付け、注記は冒頭の1回のみ。距離や接続・通行可否を確認できなければ「未算出（NOT_RUN）」。**標準歩行＋寄り道歩行＋見学＋休憩＋安全余裕**を合計するとき同じ時間を二度足さない。

### 標高×予定月から装備へ：簡潔な季節判定

**「高山に平地の夏はない。高所は春秋・冬・厳冬のつもりで考える」**は低温を忘れないための説明用比喩であり、全国共通の固定季節表ではない。**山頂標高でなくコースの通過最高標高**を使う。

| 判定入力（目安） | 仮分類と回答用の定型句 |
|---|---|
| 〜999m／凍結・残雪なし | **通常の低山歩き**：「速乾服＋薄手の防風・雨具。歩きやすい靴、飲料、地図、ライトを」 |
| 1,000〜1,999m／温暖期・雪氷なし | **高地の冷えに注意**：「速乾服を重ね、フリースなどの保温着と防水シェルを追加」 |
| 2,000m以上／温暖期・雪氷なし | **高山の寒冷・強風を想定**：「平地が夏でも防寒着・雨風を遮る上着・手袋。天気急変と日没を優先」 |
| **標高を問わず**、冬期・氷雪・強風・低体温リスクの疑い | **冬山条件を別判定**：「一般的な初心者コースとして推奨しない。積雪・凍結と必要技術・装備を確認し、対応できなければ別ルート／別日へ」 |

気温は**周辺観測地の値から標高差100m当たり約0.6℃低下**を試算（気象庁の一般的な目安）。計算上の気温は現地点の予報そのものではない。降水・風・北斜面・地形・季節・残雪で大きく変わる。予定日があれば現地予報を優先し、予定月しかなければ「季節上の予備判断」として提示。特に標高2,000m級の春・秋や降雪地域の冬は、暦上の春夏に安全な無雪期と決めつけない。梅雨・熱中症・雷・台風・短い日照も確認する。

**共通の持ち物を長く毎回列挙しない**：登山に適した靴、雨具、防寒1枚、飲料・行動食、ライト、オフライン地図・電源を基本とする。ポール・手袋・防虫・帽子などは季節・地形で追加。氷雪・鎖場・難しい岩場では「アイゼン等を持てば初心者OK」としない。同行者の年齢・経験・装備・天候で適合判断を更新する。

根拠：[気象庁（100m当たり約0.6℃）](https://www.data.jma.go.jp/nagoya/shosai/chara/tokusei_aichi.html)。季節比喩・重ね着の着想は旧来の登山入門記事から一般化したもので、個人文書のURLや引用は共有しない。

## 最小品質ゲート（3つの確認ループ）

| ループ | 確認すべき欠落・やめる条件 |
|---|---|
| **1 検索** | 原型の**直接URL**、実ルート、距離・時間・上り下りと本人の希望が対応するか。**適合したらヤマレコ・海外へ無用な追加検索をしない**。 |
| **2 旅程** | 希望との差分、登山道／道路の区別、見どころの寄り道、3交通方式の往復、交通費・時間の計算、**歩行・見学時間の二重計上**がないか。 |
| **3 季節・安全・表示** | **通過最高標高・予定月→気象・残雪で補正**、規制・下山時刻・撤退条件、確認日と未確認点。文章の重複、3方式ごとの見どころ再掲、未検証の架空料金・時刻を削ったか。 |

判定は**PASS（根拠あり）／FAIL（不成立）／NOT_RUN（未確認）／N/A（理由付き対象外）**。必要な安全情報がNOT_RUNの段階では「現地で安全に実行可能」と保証せず、条件付き計画に留める。新規コースの実地適合・利用者評価は文書の自己検査とは別。

## 小さな回帰試験（本文の例は架空数値を埋めない）

- **屯鶴峯・初心者2時間・神社・車**：YAMAP約1時間の原型を選ぶ→神社は下山後の車移動で補う→車移動を登山歩行に含めず、見どころを1表だけ。規制と道路を別確認。
- **2,500m級・5月・初心者**：月と高度だけで「春のハイキング可能」と表示せず残雪の現況へ分岐。通常装備のままなら別日・低山を提示。
- **駅からの縦走・帰りがバスのみ**：最終便未確認なら交通方式の行は残して NOT_RUN。終点と駐車場が別ならマイカー往復成立を推測しない。
