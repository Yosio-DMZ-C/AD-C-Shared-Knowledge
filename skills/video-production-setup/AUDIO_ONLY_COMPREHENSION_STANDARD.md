# 動画制作標準｜音声単独理解の原則

- 版：Draft v0.4（2026-10-26）
- 対象：主に解説・教育・PR動画。映像主体の作品は必要に応じて適用。
- 位置づけ：一般向け動画制作の標準。シリーズ固有のRunbook・採用済み制作資産を上書きしない。

## 1. 基本原則

**耳だけで話が分かり、画面を見るとさらに理解が深まる動画を作る。**

- 音声だけで、重要な内容と結論が理解できること。
- 映像は理解の補強・証拠の提示・演出に使う。
- **音声だけで伝えるために、説明を長くしない。**

目指すのは「詳しく説明すること」ではなく、**短く、分かりやすく伝えること**。

操作実演や視覚鑑賞など、映像自体が主目的の場合は例外とする。

## 2. 制作手順

**① 伝えたいことを決める**

視聴者に何を理解してほしいのか、一文で明確にする。

**② 音声だけで成立する台本を作る**

- 原則として音声だけで成立する台本を先に整える。ただし、既存の採用原稿がある場合はそれを優先し、必要な箇所だけ修正する。
- 画面がないと意味の通じない表現を避ける。
- 一度聞いて理解できる、自然で簡潔な言葉を使う。
- 事実・推測・未確認を区別する。
- 説明を増やすより、伝え方を短く明確にする。

**③ 映像で理解を補強する**

台本に合わせて図・実演・文字・キャラクターを配置する。重要な情報を映像だけに追加しない。

## 3. 品質検査

**検査①｜音声単独理解（台本）**

映像なしで次の三点が分かるか。

1. 何の話か。
2. 何が分かったか、または何をすればよいか。
3. 結論は何か。

**検査②｜完成音声**

ナレーション・BGM・効果音を実際に聞いて確認する。

- 聞き取りやすく、意味が伝わるか。
- 冗長な説明や不要な繰り返しがないか。

重要な問題があれば該当部分を修正する。原稿検査と完成音声検査は別判定とし、既存のPASS／FAIL／NOT_RUNを利用する。独立した管理台帳・品質ゲートは増やさない。
