# 動画制作・初期設定｜Designer’s Note

> 2026-11-18、Playbook改訂時の近傍ノート配置ルールに従い、既存SKILL.mdのHTMLコメント内にあった局所設計理由を原文のまま移設。採用済み実行条件は[SKILL.md](SKILL.md)が正本。通常制作では読込不要。

この制作資料に固有の設計理由。通常の制作作業・生成プロンプトには注入せず、仕様改訂・障害・責任者間の検討で必要なときだけ参照する。既存の確定素材や専門条件を変える命令ではない。
設計の背景：動画や編集可能PPTを一つのシリーズで継続して作れるように、案件・シリーズの正式採用PPT、原稿、素材ID、声と利用条件を別々に保持して最小の自然文から復元する。過去の制作結果や候補は今回の本人採用と混同しない。
設計の理由（PPTの視覚性）：人間は画面を視覚的に見て内容を探すため、意味が合う小さなアイコンは視線誘導や見通しの助けになり得る。AIのテキスト中心の最適化で不用意に省かず、しかし確定済み構図を壊したり効果を実証済みと断言したりしない。
変更時に守る点：既存の採用済みPPT・シナリオ・公式素材・固定文字・生成プロンプト・音声判断・ロック済み工程を無断改変しない。創作工程のPythonナビ統一はこの変更で決めず、既存PR責任者との相談・一問一答で採否判断する。非公開の原本URLやVoice IDを公開正本へ転載しない。
