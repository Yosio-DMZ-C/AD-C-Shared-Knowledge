# 制作素材 一般仕様表 v0.1（2026-10-25）

> **共有KBの正本（Draft）**：解説・PR動画向けの再利用可能な制作素材セット。AD&C固有の制作指示・インストール必須物ではない。**画像・動画・PPT制作を希望する場合に限り**、現在の作品で必要な素材を特定するために使用する。

**出典と検証状態**：2026-10-25に利用者が提示した「制作素材 一般仕様表 v0.1」の項目・使いどころ・状態を一般仕様とプロジェクトの記録に分離して保全したもの。右端の「AD&Cの状態」は**提出時の自己申告／整理結果**であり、リーダーが全原本を独立取得して検証した結果ではない。現行の採用や所有を証明しない。別プロジェクトでは自分の状態に差し替える。**表の状態列はAD&Cの例示であり、他利用者への採用済み配布物ではない。**

**使い方（KB構築時の任意工程）**：
1. [共通実行標準 §6.3.2](https://github.com/Yosio-DMZ-C/AI-DODAI-Continuity/blob/main/docs/PROJECT_EXECUTION_STANDARD.md)に従い、作業Runbook冒頭の**「必要資料・素材・ツール」**一か所から採用素材へ到達する。
2. この表は**候補の分類表**。8種類のロゴ・すべての人物ポーズ・約40点のアイコンを最初から全件生成する義務ではない。実制作に必要なものだけ、既存の原本・権利・採用状態を確認して採用する。使わないカテゴリは理由付きN/A。
3. 同じ仕事で比較・選択する画像が2枚以上なら、番号・素材ID・採用状態が分かる**一つのコンタクトシート／視覚一覧**を用意する。視覚一覧は閲覧用で、個別画像原本・透過・編集可能なデータを置き換えない。
4. 既存の`30_contexts/Areas`（シリーズ基準）・`30_contexts/Projects`（案件採用／残件）・registryの**実ID・版・権利・原本所在**を利用。表の「あり／使用中／定義済み」は、当該ファイルを実取得して使えることとは別。未取得はNOT_RUN、不足を勝手なロゴ生成・似た素材で補わない。
5. 未整備や最終承認待ちは既存のTASKS／Project／Issueの当該タスクに残し、文書に「完成」と書いただけでDONEへ変えない。

### B-4 人物素材の技術仕様（一般）

- 背景は単色に寄せ、切り抜き・合成ができること
- バストアップは短辺1,200px級以上（サムネイルで大きく扱えること）
- 画風・線の質感・色調は全役で統一
- 視線のバリエーション（カメラ目線／斜め／横顔）を最低限そろえる
- 全身図は原則作らない（立ち絵が要る媒体がある場合のみ例外）
- 背景付きの場面絵は作らない（場面は都度合成・生成）

ここでの寸法・ポーズは**対象媒体に合わせて適用する一般目標**。ユーザーが作らないと決めた人物役や媒体への生成を強制しない。正式採用には見本・縮小時の可読性・本人が判断する範囲の承認を別途確認する。

## 表D：PPT・動画PPTX・Word等の文書に共通するアイコン探索（テキスト入口＋既存SVG早見シート／2026-11-10）

**形式の適用範囲**：この表Dのアイコン名・公式SVG・ライセンスは、PPTだけでなくWord（DOCX）・Google Docs・Writer等の文書でも必要に応じて再利用できる。文書の構成・編集・再描画は[文書作成Playbook](../document-authoring/SKILL.md)を正とし、動画／サムネイルの採用済み素材・工程は変更しない。**ドキュメントの本文が主、アイコンは意味のある案内表示のみ**。Word対応は既存素材の用途追加であり、正式配布・独立AI検証を意味しない。

**使い方の要点**：細かな図形をゼロから描くより、無料で利用条件が明示された既存SVGアイコンを**候補として先に探す**。ただし、アイコンの使用数・位置・色・演出・有無は作品目的に応じた裁量。写真・図解・イラスト・生成画像の方が適切ならそちらを選ぶ。**全スライドへのアイコン配置、約40点の一括制作、毎回の全件検索は不要**。本MarkdownをAIが読む操作入口にし、見本画像を本文には埋め込まない。

**素材への1入口**
- **実SVGを使った1枚の早見シート**：[PPT用アイコン素材｜Lucide＋Tabler（16点の実アイコン見本・文字ラベル付き）](../../assets/ppt_icon_reference_sheet.svg)。SVG内に見本名、`data-icon`、原本URL、取得時点のライセンス原文を収録。**一覧は候補発見用の参考画像であり、全件配布物や個々の編集用SVGの代替ではない**。
- **主推奨**：[Lucide Icons](https://lucide.dev/icons/)／[公式ソース](https://github.com/lucide-icons/lucide/tree/main/icons)（ISC。Feather由来の一部はMITの表記も継承）。
- **補助**：[Tabler Icons](https://tabler.io/icons)／[公式ソース](https://github.com/tabler/tabler-icons/tree/main/icons/outline)（MIT）。
- **参考**：[Feather Icons](https://feathericons.com/)（MIT）。画像には参照URLのみ載せ、別途全件収録を要求しない。

**画像を開く前にテキストで探す（AI向けの探索語）**

| 意図・場面 | この早見シートにある実サンプル名（検索用） | AIの使いどころ |
|---|---|---|
| 感情・表情 | `mood-smile`／`mood-sad`／`mood-neutral`（Tabler）、`heart`（Lucide） | 喜び、落胆、迷い、共感・好意 |
| 注意・肯定 | `check`（Lucide）、`bell`（Tabler） | 確認、完了、通知 |
| 動作 | `search`／`pencil`／`download`（Lucide）、`arrow-right`／`send`／`refresh`（Tabler） | 検索、編集、取得、進行、送信、更新 |
| 情報整理 | `folder`／`calendar`／`clock`（Lucide） | ファイル整理、予定、時間 |
| 発想・ひらめき | `bulb`（Tabler） | 発見、アイデア、解決 |

**実行の流れ（必要なときだけ）**：
1. 制作したい意味・動作から、上記の**テキスト表を先に探す**。候補が分かれば見本画像を開かず、元の公式SVGへ進んでよい。
2. 形を比較したいときだけ上記**早見シート1ファイルを開く**。画像を見られるツールなら目視／画像理解で候補を選ぶ。SVGのテキストを解析できるなら**`data-icon`／表示ラベルを直接検索**する。**OCRはテキスト解析が使えない場合の補助手段**とし、毎回義務化しない。
3. 気に入った見本の**正式なアイコン名**で公式サイト／公式リポジトリから**個別の元SVG**を選び、作品に取り込む。早見シートのアイコン抜き出しを編集用原本として前提にしない。取得した版と適用ライセンス／著作権表示を尊重する。
4. 見つからない・合わない場合は **Lucide → Tabler → Feather（参考）** へ移る。必要なら他の適法素材や独自表現へ切り替え、無意味な探し続けをしない。

**表示形式の差**：公式SVGを最終原本として保持し、Word等の対応環境でSVGが不安定ならPNGへ変換して挿入する。SVG見本シートは候補選択専用。画像化したアイコンと編集可能な本文・表・見出しは別要素であり、見た目の確認は実際に出力した文書で行う。変換結果の全アプリ互換性は未実証。

**権利と状態**：ISC／MITは無償商用利用や再利用に適したライセンスだが、**著作権表示・ライセンス文面保持等の条件は残る**。「将来も無条件で一切違反しない」とは言わない。2026-11-10時点で本見本の原本とライセンスを取得し、実SVGを組み合わせた**見本ファイルをGitへ保存**した。適切なPPT／動画での見た目・AIによる独立再探索・編集可能PPTXへの組込みの実証は**NOT_RUN**。既存の2026-10-25案「24×24／2px・約40点のSVGスプライト」は参考履歴であり、全員への配布・生成義務ではない。

## 必須の検収（該当制作に限る）

| ゲート | PASS条件 | 失敗・未実施の扱い |
|---|---|---|
| A/B/C/Dの**適用範囲の選択** | 今回の作品に必要な種類と不要な種類が、正式な案件判断に沿っている | 未決定は候補で保留。「表にあるから全て必須」にしない |
| 原本と採用判断 | 現行版・本人承認・権利・実体IDを各必須素材に紐付けて実取得 | 旧ロゴや類似生成で無断代用しない |
| 複数画像の見落とし防止 | 一覧のID／件数が原本群・Runbookと一致。縮小時にも判読可能 | 不一致FAIL、未取得NOT_RUN。見た目の一覧だけでPASSにしない |
| ツールやSVGの使用 | 実ファイルの取得、必要環境での表示／実行を確認 | 配布予定や「定義済み」だけではNOT_RUN |
| 受渡し | Runbook冒頭から必要なファイル・本人判断・未完了へ到達 | 他AIの独立Q2／実制作Q3は試験がなければNOT_RUN |
