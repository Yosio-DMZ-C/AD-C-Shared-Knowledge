# サムネイル2A｜一行制作入口（2026-11-20／既存仕様の実行導線）

**目的**：自然文1行で、作品別の確定コピー・公式原画・ブランド規則を復元し、創作は中央の訴求に集中させて、1280×720 PNG＋320×180縮小確認画像を完成させる。一般向けの新しい別Playbookや新しい承認ゲートは作らない。動画本編・PPT・音声・公開は起動しない。

## 利用者の入口（例）

`MUSE特別編 第3話のYouTubeサムネイルを、作品STATEの確定文言と公式「私」＋MUSE素材で作成して。`

作品STATEに確定コピーがない初回だけ、本人が同じ一行に主見出し・副見出しを記載する（この文字列を変更・要約・誇張しない）。初回から別のAI/新チャットでも「確定文言」が復元できるよう、採用された作品STATE・HANDOFFの既存欄に文面と公式素材のID/出典を保全する。

## 実行の一本道（実際に仕事を始めるAI向け）

1. **仕事を限定**：依頼された作品のサムネイル2Aのみ。使用するものは、シリーズArea・作品STATE/HANDOFFの採用コピーと採用公式素材、既存の個別動画Runbookの**サムネイル§8.0B〜8.5**。初回で分かるものを再質問しない。既存CASE Aの`00_TASK.md`・古い4行コピー・凍結画像を新作の文面へ混ぜない。
2. **素材を自力取得**：接続された非公開KBに記録された公式「私」（バストアップ）・選択済みMUSEマスコット・AD&Cロゴの**実ファイル**を取得する。MUSEであれば既存公式素材集のMUSEマスコットを使い、女性「ワタシ」や別人物を自動追加しない。取得不能のときだけその素材を指名して報告し、本人へすべての素材の再アップロードを求めない。一般向け公開GitHubへ非公開Drive ID、原画、個人素材を転記しない。
3. **構図ガイド→創作**：背景にAI画像生成を用いるときは、先に公式画像の配置領域・文字安全領域を示す構図ガイドを作る。画像生成には**そのガイドを実入力**し、背景の光・奥行き・色と中央の視線誘導だけを創造させる。新しい絵に公式人物、マスコット、ブランドロゴや日本語タイトル・説明書・検証結果を描き込ませない。美術面で不満が残る場合、制作履歴を長々と画像生成へ渡さず、作品内容＋見せ場だけで改善する。
4. **公式原画と文字の後合成**：当該個別Runbookが指定する既存`r7_postprocess.py`/CASE Aが使える**同一条件の既存作品だけ**それを使用し、任意の新作では[可搬の後合成器](tools/thumbnail_compose.py)を使う。後者は `Pillow` / `Noto Sans CJK Bold` が必要で、画像生成自体は行わない。採用素材の比率を保持し、ロゴ右下小サイズ、キャラの顔は原画そのもの、テキストは確定Unicodeを日本語フォントで組版する。元画像は上書きしない。
5. **実物で見る**：1280×720と320×180の2枚を表示し、「主見出しが最初に読めるか」「副見出しが読めるか」「人物・マスコットが不自然に浮かないか」「誇張・追加文字がないか」「元絵とロゴが変わっていないか」を目視で判定。Pythonの`MECHANICAL_PASS_VISUAL_PENDING`は**美術的PASSではない**。読めない文字だけ局所組版し、背景が弱いときだけ中央の創作を改善する。最終成果は2つのPNGと簡潔な実測結果。
6. **保存と次の一手**：作品STATE/HANDOFFに採用文面、公式素材出典、生成背景の出典/生成履歴、PNG、QA、採用/未採用を記録する。保存・読戻しはできたときだけPASS。動画本編2Bへはユーザーの採用または既存作品STATEの確定条件に従って戻し、自動公開しない。

## 自動組版器の契約

次のような作品別JSON（利用者に直接書かせず、AIが既存STATEから一時生成）を作り、背景PNGと公式PNGをファイルとして置く。

```json
{
  "headline": "確定済み主見出し",
  "subtitle": "確定済み副見出し",
  "headline_lines": ["確定済み", "主見出し"],
  "subtitle_lines": ["確定済み副見出し"],
  "assets": {"host": "official-host.png", "mascot": "official-mascot.png", "logo": "official-logo.png"}
}
```

**注意**：`headline_lines`・`subtitle_lines`を連結した文字列は確定文面と完全一致させる。改行以外の変更は禁止。先に非生成の構図ガイドを実画像として作り、画像生成ツールに実際に参照画像として渡す（画像参照できない場合は未実施と記録する）。

```bash
python thumbnail_compose.py --manifest recipe.json --guide-only --outdir result
```

出力された `result/guide_1280x720.png` を参照して中央背景だけを画像生成し、公式人物・ロゴや文字をモデルに描かせない。生成背景を保存した後、同じ後合成器で文字と公式素材を戻す：

```bash
python thumbnail_compose.py --manifest recipe.json --background central_art.png --outdir result
```

出力：`result/thumbnail_1280x720.png`、`result/preview_320x180.png`、`result/qa.json`。公式画像をソースピクセルから切り出して透過化した作業用素材を使う場合、その派生元と輪郭処理を記録し、正式原画そのものと同一ファイルと偽らない。

## できる範囲

画像生成モデルの呼び出しは接続されたAIの画像機能を使用。Python合成器は**生成画像を作り出さない**。画像生成ツールの利用可否、非公開素材への権限、保存先アクセスが別AIで変わる場合、どの工程が未実施かを短く示し、できた工程は保全する。共通入口にリンクがあっても新チャットの自動読込までは保証しない。初回は「一行→実際の完成品」の実地試験で判定する。
