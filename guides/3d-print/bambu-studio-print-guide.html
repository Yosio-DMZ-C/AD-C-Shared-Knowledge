1. 最初はメーカーのプリセットから

① プリンターとノズルを指定機種／ノズル径／造形範囲
② 素材プロファイルを選ぶ銘柄・素材ごとの温度、流量、冷却
③ 印刷目的を一つ決める見た目・強さ・寸法・速度の優先順位

初回は温度・速度をまとめて弄らない。 メーカー／素材の既定プロファイルを出発点に、気になる品質項目だけ一つずつ変えてスライス前後を比較します。ノズル・プレート・素材の組み合わせに合わない設定を他機種からコピーしません。

設定値や表示位置はBambu Studioの版、プリンター、ノズル、フィラメントで変化します。ここでの数値は試験の出発点であり、「Bambu公式推奨値」や全機種共通の正解ではありません。

2. 外壁を石肌にする：Fuzzy Skin

Fuzzy Skin（ファジースキン）は外壁の経路にランダムな凹凸を付ける機能。ケルト風・石造風・木肌風の意匠や、積層線を目立ちにくくする用途に向きます。単なる「ランダムなZシーム」とは別設定です。

設定・操作意味と使い方注意
Fuzzy SkinNoneから必要なモードへ。基本は外壁側の装飾上面の模様を作る機能とは区別
Fuzzy skin thickness凹凸の強さを調整。小さいほど控えめ嵌合寸法の外側へ影響しうる
Fuzzy skin point distance凹凸の変化する間隔を調整粗すぎ・細かすぎは実物で比較
Fuzzy Skin Painting表面を選んで質感を塗り分ける（Studio 2.2.0で導入）意匠面のみ。接触面・ネジ穴・差込面は避ける
小物での控えめな試験例（非公式）：厚み0.10mm前後、点間距離0.5mm前後から少しずつ調整。0.4mmノズル／PLAの試行を想定した例であり、0.2mmノズルや嵌合品にそのまま適用しない。凹凸が強いほど見た目は変わりますが、外形・隙間・引っ掛かりも変化します。

ダイストレイの例：外側の石柱だけをFuzzy Skin Paintで加工し、柱が入り込む内側、スリット、ロゴ文字、底の合わせ面は滑らかに残します。実物を装飾前後で比べるまでは、嵌合が良くなるとは扱いません。

根拠：Bambu Studio 2.2.0リリースノート（選択的Fuzzy Skin）、Bambu WikiのFuzzy Skin項目。

3. 「上面を密にする」は3種類ある

混同しやすいのがトップシェルの積層数、上面の表面パターン／密度、上部空間の内部充填率です。目的に合ったものだけ変更します。

やりたいこと触る設定期待できること
一番上の面を隙間なく覆いたいStrength → Top/bottom shells → Top shell layers / Top shell thickness上面のソリッド層を厚くして下の充填パターンが透ける・沈むのを抑える
上面の線の見た目を改善したいTop surface pattern / Top surface density／Quality → Ironing一番上の表面の線配置や平滑さを変える。内部の中身を密にする意味ではない
上側の内部だけ強くしたいModifierやHeight Range Modifier → Sparse infill density上の特定領域に限って内部充填を増減できる
トップシェルの試行例（非公式）：積層0.20mmなら4〜6層（0.8〜1.2mm相当）を比較する。実際のトップシェル厚さの制御は設定項目・計算方法に依存し、0.20mm×5という単純化だけで全てが決まるとは限らない。重要なのはスライス後のプレビュー。

4. 上側だけ内部充填率を上げる：Modifier

全体を高充填にするより、必要な場所だけ設定を変える方法。Bambu Studioのモディファイア（Modifier）は、指定領域だけスライス設定を上書きします。版によってはHeight Range Modifier（高さ範囲）でZ範囲を直接指定できます。

  1. STLを配置し、対象のオブジェクトを選択。右クリックからAdd modifier → Cubeなど、または高さ範囲のModifierを選ぶ。
  2. キューブの場合は上部の指定範囲だけを覆うよう、位置・高さ・大きさを調整する。キューブ自体は追加の印刷物ではありません。
  3. Objects／オブジェクト別設定でModifierを選び、Sparse infill densityだけ上書き。まずは例えば基本15%→上部25%という比較試験用の仮値から。
  4. Slice → Previewで、その高さより上だけ充填パターンが変わっているか確かめる。目的のない全項目上書きはしない。
今回のダイストレイでは注意：柱やスリットのような薄い形状では「内部充填率」を上げても効果が小さい場合があります。柱の強度は壁の周回数・実肉厚・積層方向も重要です。まず外壁とトップ層、必要なら局所Modifierを検討してください。

根拠：Bambu LabフォーラムのModifier公式Wiki案内、Modifierによる充填率変更の解説。

Ironingはどんなときに使う？

ノズルを最上面に再走査させ、平滑さを改善する選択肢です。上面の小さな文字や繊細な凹凸がある部分では、まず無効で比較してください。流量・間隔・速度は素材と表面形状に依存し、標準値を一律に増減させません。

Variable Layer Heightは充填率と違う？

はい。レイヤーの高さを部分的に変えて曲面や段差の見た目を調整します。内部充填率を上げる機能とは別です。小さなR面などに効果がある場合もありますが、印刷時間とのトレードオフを確認します。

Fuzzy Skinと細かいロゴは両立する？

可能性はありますが、ロゴ面を滑らかに残すのが優先。凹凸の境界を塗り分け、ロゴの溝や線が実際のノズル幅に対して細すぎないか確認します。画像上の高解像度とSTL・印刷解像度は別です。
