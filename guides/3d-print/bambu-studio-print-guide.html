1. 最初はメーカーのプリセットから

① プリンターとノズルを指定機種／ノズル径／造形範囲
② 素材プロファイルを選ぶ銘柄・素材ごとの温度、流量、冷却
③ 印刷目的を一つ決める見た目・強さ・寸法・速度の優先順位

初回は温度・速度をまとめて弄らない。 メーカー／素材の既定プロファイルを出発点に、気になる品質項目だけ一つずつ変えてスライス前後を比較します。ノズル・プレート・素材の組み合わせに合わない設定を他機種からコピーしません。

設定値や表示位置はBambu Studioの版、プリンター、ノズル、フィラメントで変化します。ここでの数値は試験の出発点であり、「Bambu公式推奨値」や全機種共通の正解ではありません。

2. 外壁を石肌にする：Fuzzy Skin

Fuzzy Skin（ファジースキン）は外壁の経路にランダムな凹凸を付ける機能。ケルト風・石造風・木肌風の意匠や、積層線を目立ちにくくする用途に向きます。単なる「ランダムなZシーム」とは別設定です。

設定・操作意味と使い方注意
Fuzzy SkinNoneから必要なモードへ。基本は外壁側の装飾上面の模様を作る機能とは区別
Fuzzy skin thickness凹凸の強さを調整。小さいほど控えめ嵌合寸法の外側へ影響しうる
Fuzzy skin point distance凹凸の変化する間隔を調整粗すぎ・細かすぎは実物で比較
Fuzzy Skin Painting表面を選んで質感を塗り分ける（Studio 2.2.0で導入）意匠面のみ。接触面・ネジ穴・差込面は避ける
小物での控えめな試験例（非公式）：厚み0.10mm前後、点間距離0.5mm前後から少しずつ調整。0.4mmノズル／PLAの試行を想定した例であり、0.2mmノズルや嵌合品にそのまま適用しない。凹凸が強いほど見た目は変わりますが、外形・隙間・引っ掛かりも変化します。

ダイストレイの例：外側の石柱だけをFuzzy Skin Paintで加工し、柱が入り込む内側、スリット、ロゴ文字、底の合わせ面は滑らかに残します。実物を装飾前後で比べるまでは、嵌合が良くなるとは扱いません。

根拠：Bambu Studio 2.2.0リリースノート（選択的Fuzzy Skin）、Bambu WikiのFuzzy Skin項目。

3. 「上面を密にする」は3種類ある

混同しやすいのがトップシェルの積層数、上面の表面パターン／密度、上部空間の内部充填率です。目的に合ったものだけ変更します。

やりたいこと触る設定期待できること
一番上の面を隙間なく覆いたいStrength → Top/bottom shells → Top shell layers / Top shell thickness上面のソリッド層を厚くして下の充填パターンが透ける・沈むのを抑える
上面の線の見た目を改善したいTop surface pattern / Top surface density／Quality → Ironing一番上の表面の線配置や平滑さを変える。内部の中身を密にする意味ではない
上側の内部だけ強くしたいModifierやHeight Range Modifier → Sparse infill density上の特定領域に限って内部充填を増減できる
トップシェルの試行例（非公式）：積層0.20mmなら4〜6層（0.8〜1.2mm相当）を比較する。実際のトップシェル厚さの制御は設定項目・計算方法に依存し、0.20mm×5という単純化だけで全てが決まるとは限らない。重要なのはスライス後のプレビュー。

4. 上側だけ内部充填率を上げる：Modifier

全体を高充填にするより、必要な場所だけ設定を変える方法。Bambu Studioのモディファイア（Modifier）は、指定領域だけスライス設定を上書きします。版によってはHeight Range Modifier（高さ範囲）でZ範囲を直接指定できます。

  1. STLを配置し、対象のオブジェクトを選択。右クリックからAdd modifier → Cubeなど、または高さ範囲のModifierを選ぶ。
  2. キューブの場合は上部の指定範囲だけを覆うよう、位置・高さ・大きさを調整する。キューブ自体は追加の印刷物ではありません。
  3. Objects／オブジェクト別設定でModifierを選び、Sparse infill densityだけ上書き。まずは例えば基本15%→上部25%という比較試験用の仮値から。
  4. Slice → Previewで、その高さより上だけ充填パターンが変わっているか確かめる。目的のない全項目上書きはしない。
今回のダイストレイでは注意：柱やスリットのような薄い形状では「内部充填率」を上げても効果が小さい場合があります。柱の強度は壁の周回数・実肉厚・積層方向も重要です。まず外壁とトップ層、必要なら局所Modifierを検討してください。

根拠：Bambu LabフォーラムのModifier公式Wiki案内、Modifierによる充填率変更の解説。

5. 美観・強度・精度を分けて調整

困りごとまず確認する設定確認すべき落とし穴
上面の筋やザラつきTop shell layers、Top surface pattern、IroningIroningは平らな上面向き。細い刻印・凹部では悪化の可能性
小さな装飾が潰れるLayer height、ノズル径、外壁速度、モデル実寸スライサーにない細線は印刷できない。プレビューで線幅と経路を確認
柱が折れやすいWall loops、実肉厚、造形方向、材料充填率だけで強度は決まらない
差し込みで引っ掛かるFuzzy Skinの適用面、Elephant Foot Compensation、クリアランス設計上干渉ゼロでも造形誤差がある。最終形だけでなく挿入途中も見る
底が剥がれる／反るベッド清掃、素材とプレート適合、BrimBrimが差込面へ残ると誤差になる。除去後に測る
縫い目（Zシーム）が目立つSeam position、Seam paintingRandom seamはFuzzy Skinではない
Ironingはどんなときに使う？

ノズルを最上面に再走査させ、平滑さを改善する選択肢です。上面の小さな文字や繊細な凹凸がある部分では、まず無効で比較してください。流量・間隔・速度は素材と表面形状に依存し、標準値を一律に増減させません。

Variable Layer Heightは充填率と違う？

はい。レイヤーの高さを部分的に変えて曲面や段差の見た目を調整します。内部充填率を上げる機能とは別です。小さなR面などに効果がある場合もありますが、印刷時間とのトレードオフを確認します。

Fuzzy Skinと細かいロゴは両立する？

可能性はありますが、ロゴ面を滑らかに残すのが優先。凹凸の境界を塗り分け、ロゴの溝や線が実際のノズル幅に対して細すぎないか確認します。画像上の高解像度とSTL・印刷解像度は別です。

困った症状から探す / 実例で学ぶ

6. 症状から解決する小技5選

「設定名を覚える」よりも、①何が起こったか → ②原因候補 → ③スライスのPreviewでどの層・経路が違うか → ④設定を1つだけ変える → ⑤試し刷りで比較の順で考えます。以下はAge of 3DP / ウノケンの5つの小技の動画で紹介された観察を起点に、既存ガイドとメーカー資料に照らして再編集したものです。動画の印刷例は特定条件の結果であり、すべての機種での再現保証ではありません。

① 側面に横筋やへこみが出る：内部ブリッジの引っ張りを疑う

症状：水平な底・棚の少し下に、外壁の横筋や内側へのへこみが現れる。原因候補：内部の橋渡し（ブリッジ）の収縮や支持構造が壁を引く可能性。動画の説明に基づく仮説であり、筋の原因はこれだけではありません。

まず見る：Previewの対象高さでBridge／Internal solid infill／Sparse infillの経路を表示し、横筋の位置と橋渡しの接続位置が一致するか。小変更：内部充填パターン・密度を一つずつ変え、壁への接続と支持不足がどう変わるかを比較。必要なら設計形状を見直す。

副作用：内部充填やブリッジの変更は上面の支持・強度・印刷時間にも影響。パターン変更だけで「橋が壁に触れなくなる」とは限らない。上面シェルと内部充填の区別も参照。

② 部品がはまらない：象の足とシームを別々に確認

症状：設計では入るはずの箱やトレイが、底付近や角で止まる。まず見る：部品の底の張り出しと、角・接触面のZシーム（層の開始・終了点）を分けて確認。まずベッドや初層の状態を点検する。

小変更：QualityのElephant foot compensationで底層を少し内側へ補正し、Previewと実寸で比較する。シームが干渉する場合はSeam position／Seam paintingで嵌合面の外へ逃がす。Randomで分散する方法もあるが、表面全体に細かな点が増えるため無条件には推奨しない。

副作用：底の補正量を増やしすぎると底面寸法が小さくなりすぎる。補正値0.2mmなどは動画の一事例で、普遍的な推奨値ではない。最終姿勢だけでなく挿入途中と保持感も評価。嵌合の基本を参照。

③ シルクPLAにうっすら縞：外壁の速度差を疑う

症状：形状の切替えやオーバーハング付近の高さに沿って光沢が変わる。まず見る：PreviewのSpeed／Flow表示で、縞の高さと外壁速度・流量の変化が一致するか。

小変更：該当版にあればSmoothing wall speed along Z（Z方向の外壁速度平滑化）などを比較。関連するSmooth speed discontinuity areaの係数も別設定として確認する。改善しなければ外壁速度を全体的に下げ、極端な速度差を小さくする方法を試す。

副作用：係数の大小で光沢と積層線が別方向に変わる場合がある。速度を揃えると時間が増える。機能名・既定のON/OFF・利用可能性はBambu Studioの版と機種による。Bambu Lab P2S公式マニュアル：光沢差の原因も参照。

④ サポート接触面が荒れる：対応機器なら異素材の界面を試す

症状：サポートを取ると裏面が傷んでいる。まず見る：サポートが必要な造形方向か、同一素材のSupport interface・Top Z distanceで改善できるかを検討。

応用策：対応するマルチマテリアル環境では、Support/Raft Interfaceだけに相性を確認した別素材（PLA造形に適合する専用サポート材、または検証済みのPETG等）を割り当てる。界面だけを変え、本体とサポート本体は必要に応じて従来材料のままにする。

条件・副作用：材料切替え対応、パージ量、材料間の混入・接着不良、温度・ベッド適合、追加時間と廃材を要確認。PLAとPETGを合わせれば必ず成功するわけではなく、ベッド温度を一律に片方へ合わせない。P2S公式マニュアル：サポート界面。

⑤ 小さな複数部品を効率よく作る：オブジェクト順の印刷

症状・目的：色や設定の異なる小物を、1枚のプレートで順番に完成させたい。まず見る：Others → Special mode → Print sequence: By object（対応版の名称）を確認し、By layerとの違いを理解する。

小変更：By objectへ切り替え、スライサーに表示される印刷順・各部品の必要間隔・高さ・衝突領域を確認してからスライスする。

副作用：完成済みの部品へツールヘッドやガントリーが衝突する危険がある。プレビュー・スライサーの警告・機種固有のクリアランスを優先し、無理に配置しない。高い物は順番や配置で制限が変わる。

この5つに共通するコツ：「とりあえず全部変える」はしない。失敗が再現する形状を小さく試し、Previewの変化と実物の結果を別々に記録する。問題の種類によってはモデル設計の修正のほうが早い。
