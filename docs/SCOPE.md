# 対象分野と制作範囲

これは「必要ではないか」という初期の範囲定義です。全分野の完成を約束する一覧ではありません。各テーマは独立して制作・審査し、未完成部分を必須ダウンロードにしません。

## 共通の最小構成

全分野の初期成果は主張比較資料（claim_map）を優先します。問い、主要な見解、論拠・反論、対象条件、未解決点、確認時点、関連専門家の公開見解を持ち、結論や推奨行動は必須にしません。下表の相談準備・初動等は論点の候補であり、行動手順の作成を必須とするものではありません。具体的行動を推奨する場合だけ別種のplaybookとして審査します。

初期7分野は既存Core Life Skills構想を引き継ぎます。従来の後半3分野に「組織づくり・経営・ガバナンス」を加え、**合計11分野の候補**とします。追加分野は拡張候補であり、制作順や既存の初期優先テーマを変更しません。制作順は本人の需要、見落としの影響、根拠とレビュー担当の確保で決めます。分野名だけでリスクを決めず、個々の行動の重大性・可逆性で評価します。

### 第一階層メニューと参加入口の区別

- **分野メニュー**：利用者が何を調べるか選ぶ入口。候補は`catalog.json`の`domains`で管理し、採用済み項目を意味しない。「組織づくり」はこの分野メニューに置く。
- **AD&Cへの参加・協働**：本プロジェクトに貢献する導線。`CONTRIBUTING.md`と`docs/GOVERNANCE.md`で扱い、分野やCoreセットに混ぜない。GitHub上の緩い役割分担・議論・提案をまず検証するが、専用システムの新設や権限変更は前提にしない。
- **専門家判断との境界**：正式な法人・財団、資金管理、契約等の個別判断は専門家・当事者が行う。AD&Cは開発調査の既存作法を再利用し、比較資料、必要に応じた手順候補、相談先への経路を提供する。
- **実装状態**：この分類は設計候補であり、登録されたActive項目・Core配布・非技術者向け参加UIを意味しない。

## 共通基盤として必要なもの

- 出典・主張・反証を対応させる記録。
- 専門家／専門領域の適合理由と確認時点を示す書式。
- 不確実性が残る選択の比較と見直し条件。
- 個人KB内だけに残す結果記録と、別途承認を要する共有提案。
- 正式版カタログ、品質結果、変更・撤回記録。

実在専門家の巨大な名簿、利用者ランキング、個人データを集中収集する基盤は、最初の必須範囲にしません。
