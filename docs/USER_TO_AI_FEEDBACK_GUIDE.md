# 画面の取り方（スクリーンショット）

**いま操作が止まっている画面を、そのまま1枚撮ってAIとのチャットに送ってください。** 画面を見れば、どこで困っているか確認できます。操作を長文で説明する必要はありません。

1. 下から自分の端末の撮り方を確認します。
2. スクリーンショットを撮ります。
3. AIとのチャットに画像を貼り付けるか、画像添付から送ります。

**送る前に**パスワード・認証コード・個人情報・社内機密が写っていないかだけ確認してください。写っている場合は、その部分を隠すか、画像を送らず画面の状況を文章で伝えてください。

## iPhone

サイドボタンと**音量を上げるボタン**を同時に押して、すぐ離します。ホームボタンがある機種では「サイドボタン＋ホームボタン」などになります。

[![iPhoneの撮り方を見る（Apple Support公式動画）](https://img.youtube.com/vi/2gRaIK1tQz4/hqdefault.jpg)](https://www.youtube.com/watch?v=2gRaIK1tQz4)

[動画を見る：Apple Support／2026年](https://www.youtube.com/watch?v=2gRaIK1tQz4) · [日本語の公式説明](https://support.apple.com/ja-jp/102616)

## Android

多くの機種では、**電源ボタンと音量を下げるボタン**を同時に押します。機種によって異なる場合があります。

[![Androidの撮り方を見る（Google Pixel公式動画）](https://img.youtube.com/vi/avY_VRESbNM/hqdefault.jpg)](https://www.youtube.com/watch?v=avY_VRESbNM)

[動画を見る：Made by Google／2019年・Pixelの例](https://www.youtube.com/watch?v=avY_VRESbNM) · [日本語の公式説明（機種差あり）](https://support.google.com/android/answer/9075928?hl=ja)

## Windows PC

キーボードの **Windowsキー＋Shift＋S** を同時に押し、撮りたい範囲を選びます。チャットの入力欄で **Ctrl＋V** を押すと貼り付けられる場合があります。

[![Windows PCの撮り方を見る（Dell公式動画）](https://img.youtube.com/vi/y3R_OFZUFfk/hqdefault.jpg)](https://www.youtube.com/watch?v=y3R_OFZUFfk)

[動画を見る：Dellテクニカルサポート／2025年・日本語](https://www.youtube.com/watch?v=y3R_OFZUFfk) · [Microsoft公式説明](https://support.microsoft.com/ja-jp/windows/apps/use-snipping-tool-to-capture-screenshots)

## Mac

キーボードの **Shift＋Command＋4** を同時に押し、撮りたい部分をドラッグします。画像は通常デスクトップに保存されるので、チャットへ添付します。

[![Macの撮り方を見る（Apple Support公式動画）](https://img.youtube.com/vi/hOawEk3sKoU/hqdefault.jpg)](https://www.youtube.com/watch?v=hOawEk3sKoU)

[動画を見る：Apple Support／2024年](https://www.youtube.com/watch?v=hOawEk3sKoU) · [日本語の公式説明](https://support.apple.com/ja-jp/102646)
